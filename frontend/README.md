# Frontend - Job Portal

This is the React + Vite frontend for the Job Portal application. It provides the user-facing web interface for browsing jobs, creating and managing companies, posting jobs, tracking applicants, and handling authentication.

## Tech Stack

- React
- Vite
- Tailwind CSS
- Redux Toolkit
- React Router DOM
- Framer Motion
- Lucide Icons

## Features

- Home page and job discovery experience
- Job listing and detail pages
- Candidate login and signup flow
- Company and admin dashboard pages
- Create and manage companies
- Post new jobs and review applicants
- Profile screen and protected admin routes

## Available Scripts

```bash
npm install
npm run dev
npm run build
npm run preview
npm run lint
```

## Local Development

From this folder:

```bash
npm install
npm run dev
```

The application runs by default at:

```text
http://localhost:5173
```

## API Configuration

The frontend expects the backend to be running at:

```text
http://localhost:3000
```

If your backend is running on a different port or host, update the API base URL in the frontend source before starting the app.
